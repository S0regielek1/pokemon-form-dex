# ポケモン全姿図鑑

全国図鑑 No.1〜1025 のポケモンと、リージョンフォーム・メガシンカ・キョダイマックスなどの姿違い（1,636姿）を探せる非公式のファン図鑑です。図鑑に載せなかった姿は、タグ「惜しくも不採用」で見られます。

- 公開ページ: https://s0regielek1.github.io/pokemon-form-dex/
- 「チャンピオンズ内定」タグは『Pokémon Champions』のレギュレーションM-C時点の情報です。以降の更新は予定していません。
